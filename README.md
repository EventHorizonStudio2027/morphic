# Morphic

One sentence in. A small personal app out.

Morphic turns a need — a lift log, a rent split, a plant schedule — into a Piece you can open, fill in, and change. Pieces stay in the browser. The built-in starters are instant. Anything else is generated.

## Run it

```bash
npm install
npm run dev
```

Then open the local preview the dev server prints.

## What’s here

- **Today** — the one thing each Piece is asking you to do
- **Library** — every Piece you’ve made
- **Create** — describe a need, or start from a catalog piece
- **Piece** — screens, a log, live stats, and a short change line (`rename to…`, `add a notes field`, `remind me…`)
